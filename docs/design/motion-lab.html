Motion

Quiet, fast, physical.

The system

Six tokens and seven rules. Everything on the site is built from them. No animation library: transform and opacity in CSS, plus about fifty lines of physics for the wheel. That is a deliberate call — 40 kb of runtime is a bad trade for a portfolio whose whole promise is that it feels instant.

--motion-springcubic-bezier(0.34, 1.56, 0.64, 1) — overshoot. For things the user touches: press, pop, toggle.
--motion-glidecubic-bezier(0.16, 1, 0.3, 1) — strong deceleration. For things that move themselves: panels, reveals, entrances.
--duration-fast150ms — hover feedback, colour, opacity.
--duration-base200ms — transforms, state changes, panels.
--duration-slow400ms — entrances only. Nothing exceeds 400ms except continuous physics (the wheel's lerp).
--stagger-delay50ms — list entrances, capped at 5 items then grouped.
  1. Motion is feedback, not decoration. Every animation answers "what just happened". Nothing moves on a timer; nothing loops.
  2. Fast is the feature. 150 / 200 / 400. When unsure, use the shorter one.
  3. Transform, opacity, blur — nothing else. Never animate layout. The two sanctioned morphs (identity panel, social popover) fake it with measured transforms.
  4. Blur is a transition garnish, never a resting style.
  5. Hover doesn't animate in. Row and link hover states snap (0ms in, 150ms out) — the cmdk / Linear convention. Animated hover-in reads laggy.
  6. Reduced motion is a first-class mode. Everything collapses to opacity 150ms or instant. Toggle it in the header and read this page again.
  7. Sound is optional garnish on commit actions only (Book a call, Copy email success). One very quiet tick family, synthesised in WebAudio — no assets. Desktop only. Off by default.

Button press

Press and hold. The release is where the spring earns its keep.

Where: every button on the site. The loading state keeps the fill colour and the exact width — only the label crossfades to the spinner, whose arc length varies each cycle so it never looks frozen. The button is disabled functionally, never visually. This spinner is the system's only loading state. There are no skeletons anywhere: skeletons are for content that arrives late, and nothing on this site arrives late.

press: spring · 150ms · scale 1→.97 · release overshoots — label→spinner: glide · 150ms · scale .8→1 + blur 2px→0

Palette open / close — instant

Search…

Where: the ⌘K command palette. It opens and closes instantly — no scale, no fade, no scrim tick. All content is local; there is nothing to load, so there is nothing to cover up. The palette is a tool you reach for mid-thought, and 200ms of scale-up is 200ms of waiting for a surface whose only job is to be already there. Instant is the system. 6

Hover snap — ours vs. the common mistake

Ours — 0ms in, 150ms out

The mistake — 150ms both ways

Where: project rows, palette rows, nav links — everything you sweep a cursor across. Ours is the left one. A hover state is a cursor read-out, not an event: it must be true the instant the pointer lands. Fade it in and the interface feels like it is thinking. Fading out is free, because by then you have already left.

in: 0ms · out: glide · 150ms · background + colour

Sound — two candidates, both optional

Sound fires on commit only: Book a call, and Copy email's success. Never on hover, never on open, never on a page load. It ships off. Turn the header switch on, then press the two buttons above — or audition the ticks here and tell me which one lives.

Commit actions use: A

A is a ~2 kHz body with a 30 ms decay — wooden, closer to a key press. B is a 1.2 kHz sine at 18 ms — nearly subliminal, harder to notice and harder to get tired of. Both peak at about 6% gain. Synthesised live in WebAudio, so nothing downloads.

Catalog rulings — what we took from transitions.dev, and what we didn't

  • Number pop-in — adopted. Runs the wheel year (section 7).adopted
  • Panel reveal — adopted. The identity panel.adopted
  • Menu dropdown — adopted for dropdowns and popovers.adopted
  • Text states swap — adopted, but only for the Copied state. Not a general-purpose label animator.adopted · narrow
  • Notification badge — ⌘K only, and only if badges ever exist here. Nothing else on the site should be asking for attention.conditional
  • Card resize — parked until a real use exists. No card on the site changes size today.parked
  • Gooey plus menu — parked candidate. Mobile quick actions only, and it needs restraint before it earns a place.parked
  • Modal open / close — rejected for ⌘K. Built, compared, cut: the palette is instant (section 4).rejected
  • Confetti burst — rejected. It does not fit a quiet system, and it is decoration by definition.rejected

Two rulings are worth restating because they cost the most to learn. The palette is instant — the modal recipe is good work and the wrong pattern for a tool you open mid-thought. And there are no skeletons: the site's content is local, nothing arrives late, and a skeleton for content that is already there is a loading state performing loading. The button spinner is the only loading state in the system.

Type on this page is the system stack standing in for Aeonik Pro. Spacing and weights will shift slightly once the real face is loaded; the motion will not.
